# Screen: Settings (`/settings`)

Sections as stacked sticker cards:
1. **Sound:** toggle "Play sounds" (default on), volume slider 0–100 (default 35) with a "Test" button that plays `pop`. Saved immediately; toast "Saved".
2. **Theme:** radio group System / Light / Dark.
3. **Your data:** "Download everything" (JSON export of subjects, notes, file list and extracted text; files themselves are downloadable from each subject). Link to the privacy page.
4. **Delete account:** danger card. Requires typing DELETE. Copy: "This permanently deletes your account, notes and files. It can't be undone." Button "Delete my account".
